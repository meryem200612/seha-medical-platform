# 🏥 SEHA - Medical Teleconsultation Platform

## 📖 Description

SEHA is a full-stack medical teleconsultation platform developed as a Final Year Project (PFE). It enables secure communication between doctors and patients through an intuitive web application.

## 🚀 Technologies

### Frontend
- React.js
- Tailwind CSS
- Axios

### Backend
- Laravel
- PHP

### Database
- MySQL

### Other
- PeerJS
- Git
- GitHub

## ✨ Features

- User Authentication
- Appointment Management
- Video Consultation
- Secure Messaging
- Prescription Management
- Doctor Dashboard
- Patient Dashboard
